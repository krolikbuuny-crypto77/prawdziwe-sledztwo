# RC39 — Kooperacja 2.0

Kolejna wersja RC38. Gracze mogą z dowolnego urządzenia proponować pytania do świadka, materiały do sprawdzenia i oddzielnie zaznaczyć „gotowy do finału” lub „chcę jeszcze sprawdzić”. To **doradcze głosowanie**, które **nie zmienia** prawdziwego werdyktu i nie omija reguł postępu. Właściwe przesłuchanie steruje tylko bieżący operator; propozycje są osobnym kanałem niezależnym od modeli AI.

**Nowa migracja SQL**: po istniejących 001–005 uruchom `supabase/006_coop_collab.sql` w SQL Editor. Następnie wdroż RC39. Wersje RC35.6–RC38 nie wymagają SQL 006.
