# RC38 — Tablica śledcza 2.0 i oznaczanie rozbieżności

W zakładce Notatnik dostępna jest tablica z powiązaniami dwóch już odkrytych dokumentów oraz manualnym oznaczeniem „sprzeczność do weryfikacji”. Każde oznaczenie jest **subiektywną hipotezą gracza** — nie jest dowodem, nie zmienia kanonu, nie odblokowuje nowego etapu ani werdyktu. Stan wchodzi do podpisanego zapisu JSON i synchronizacji wspólnego ekranu. Bez SQL.
