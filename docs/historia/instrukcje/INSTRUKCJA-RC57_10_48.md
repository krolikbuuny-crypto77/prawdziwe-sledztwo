# RC57.10.48 — Wyszukiwanie wiedzy AI

**Baza:** pełny projekt RC57.10.47 — 12 obszarów wiedzy i psychologii.

1. Zachowaj kopię bieżącego projektu oraz eksport zapisu gry.
2. **Zalecane:** rozpakuj `Prawdziwe_Sledztwo_RC57_10_48_WYSZUKIWANIE_WIEDZY_PELNA.zip` i wgraj jego zawartość na nową gałąź lub Vercel Preview.
3. **Alternatywnie**, gdy masz dokładnie RC57.10.47, wypakuj `Prawdziwe_Sledztwo_RC57_10_48_AKTUALIZACJA_DO_RC57_10_47.zip` do katalogu projektu i nadpisz zawarte pliki. Mała paczka nie służy do starszych wersji.
4. Lokalnie uruchom `npm run build`, `npm run check`, `npm run test:retrieval-rc48`, `node tools/test-rc57.mjs` i `python tools/test-saves.py`.
5. Dla szybkiego podglądu źródeł: `node tools/audit-retrieval-rc48.mjs MAREK "Co wiesz o Wójciku?"`.
6. W Vercel Preview sprawdź pytania do sześciu świadków o nich samych, Lenę, pozostałych świadków, zaimki, podchwytliwe domniemania, dokumenty oraz alibi przed i po północy. Wykonaj długie rozmowy i zweryfikuj zapis Supabase.
7. Dopiero po przejściu testów rzeczywistych dostawców AI i zapisów publikuj produkcję.

Nie wymagano nowych kluczy API ani migracji bazy danych. Nie publikowano projektu automatycznie.
