# Instalacja RC57.10.41

1. Zachowaj kopię aktualnej wersji projektu i eksport zapisu gry.
2. Do nowego wdrożenia Vercel Preview użyj pełnej paczki `Prawdziwe_Sledztwo_RC57_10_41_QUALITY_UX_PELNA.zip`. Nie dodawaj wyłącznie nowego CSS do dawnego HTML.
3. Alternatywnie na bazę RC57.10.40 zastosuj aktualizację: nadpisz pliki zawarte w ZIP w katalogu projektu, zachowując strukturę katalogów.
4. Uruchom `npm run build` i `npm run check`, jeśli masz Node.js w projekcie.
5. W Preview sprawdź na komputerze i telefonie wszystkie 10 modułów oraz otwartą klawiaturę podczas przesłuchania.
6. Przed produkcją sprawdź zapisy Supabase i prawdziwe odpowiedzi AI — testy lokalne ich nie zastępują.
